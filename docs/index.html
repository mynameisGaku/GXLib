GXLib API Reference

GXLib は DirectX 12 ベースの 2D/3D ゲームエンジンライブラリです。C++20 で記述され、Windows 向けの高性能なゲーム開発フレームワークを提供します。DXLib 互換 API も搭載しており、既存の DXLib プロジェクトからの移行も容易です。

最小構成サンプル

// main.cpp — GXLib 最小構成
#include "Core/Application.h"
#include "Graphics/Device/GraphicsDevice.h"
#include "Graphics/Rendering/SpriteBatch.h"

int WINAPI WinMain(HINSTANCE hInst, HINSTANCE, LPSTR, int) {
    GX::Application app;
    GX::AppConfig cfg{ L"My Game", 1280, 960 };
    app.Initialize(cfg);

    GX::GraphicsDevice device;
    device.Initialize(app.GetWindow().GetHWND(), 1280, 960);

    // メインループ
    while (app.ProcessMessages()) {
        device.BeginFrame();
        // 描画処理...
        device.EndFrame();
    }
    return 0;
}

グラフィックス技術

用語説明

HDR / LDRHigh/Low Dynamic Range。HDR は通常超の明るさを扱い、Tonemap で LDR に変換。
Bloom明るい部分から光がにじみ出す効果。
SSAOScreen Space Ambient Occlusion（環境遮蔽）。隅に自然な影を追加。
SSRScreen Space Reflections（スクリーン空間反射）。床の映り込み等。
TAA / FXAAアンチエイリアシング。ジャギー（ギザギザ）を滑らかにする技術。
DoFDepth of Field（被写界深度）。ピント範囲外をぼかす。
CSMCascaded Shadow Maps（カスケードシャドウマップ）。距離に応じた影の品質制御。
FOVField of View（視野角）。カメラが見える範囲の角度。
RTGIDXR グローバルイルミネーション。間接光を計算してシーンの明るさをリアルにする。
Toon / UTS2トゥーンシェーディング（セルシェーディング）。UTS2 ベースの3ゾーン+リム+アウトライン。
ShaderModelマテリアルの描画方式 (PBR/Toon/Phong/Unlit/Subsurface/ClearCoat)。ShaderRegistry が PSO を自動選択。
BlendTreeパラメータベースのアニメーション自動合成。1D/2D 対応。

gxpak (バンドルツール)

gxpak/

CLI バンドルツール。複数ファイルを LZ4 圧縮してひとつの .gxpak にパック/アンパック。PakFileProvider で VFS に統合可能。ゲーム配布時にアセットファイルをひとまとめにするツールです。

使い方

gxpak pack bundle.gxpak Assets/     # Assets/ 以下を bundle.gxpak にパック
gxpak unpack bundle.gxpak output/   # bundle.gxpak を output/ に展開
gxpak list bundle.gxpak             # 内容一覧表示
